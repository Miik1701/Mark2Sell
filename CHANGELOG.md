# Changelog

A short list of what changed in each version of Mark2Sell.

## [1.1.0]

- **World of Warcraft 12.1.0** — Mark2Sell is marked compatible with patch **12.1.0** (was 12.0.5).
- **BagBrother** — If **BagBrother** is loaded (including **Bagnon** / **Bagnonium**), marks, bag overlays, and the clear-marks button work in those bag windows as well as in the default Blizzard bags.

## [1.0.4]

- **New addon icon** — In the in-game **AddOns** list, Mark2Sell now shows a dedicated picture so you can spot it at a glance. The image was refreshed (less bulky than before).
- **Up to date with the game** — The addon is marked compatible with the current World of Warcraft build you’re using.

## [1.0.3]

- Earlier releases: no user-facing list was kept in this file for those versions.
